## English

### Module Responsibility

Handle automatic update checking and manual update functionality for the application.

### Feature Description

1. **Auto-check on startup** - Automatically check for new versions when the app starts
2. **Manual check for updates** - Users can manually trigger a check on the settings page
3. **Download and install** - After detecting a new version, download and prompt the user to install

### Technical Approach

Uses Tauri's official `tauri-plugin-updater` plugin, with GitHub Releases as the update source.

#### Update Flow

```
Start application
    ↓
Auto-check for updates (silent)
    ↓
New version available? → No → End
    ↓ Yes
Show update prompt dialog
    ↓
User confirms? → No → End
    ↓ Yes
Download update package
    ↓
Install and restart
```

### Interface Definitions

#### Frontend API

##### checkForUpdates()

Check if a new version is available.

**Returns:**

```typescript
interface UpdateInfo {
  available: boolean;      // Whether a new version is available
  currentVersion: string;  // Current version
  latestVersion?: string;  // Latest version
  releaseNotes?: string;   // Release notes
  downloadUrl?: string;    // Download URL
}
```

##### downloadAndInstall(onProgress?)

Download and install the update, automatically restart the app after completion.

**Parameters:**

- `onProgress` (optional): Download progress callback function `(downloaded: number, total: number) => void`

**Returns:**

- Success: Calls `relaunch()` to restart the app
- Failure: Throws error

**Note:**

In Tauri v2's `@tauri-apps/plugin-updater`, `update.downloadAndInstall()` **does not automatically restart** after completion. You must manually call `relaunch()` from `@tauri-apps/plugin-process` to restart the app and apply the update.

#### Tauri Commands

##### check_update

Check for updates.

**Returns:**

```json
{
  "available": true,
  "current_version": "0.2.0",
  "latest_version": "0.3.0",
  "release_notes": "## What's New\n- New features...",
  "download_url": "https://github.com/..."
}
```

##### install_update

Download and install the update.

### Configuration

#### tauri.conf.json

```json
{
  "bundle": {
    "createUpdaterArtifacts": true
  },
  "plugins": {
    "updater": {
      "endpoints": [
        "https://github.com/shulain/MobausStudio/releases/latest/download/latest.json"
      ],
      "pubkey": "YOUR_PUBLIC_KEY"
    }
  }
}
```

#### Generate Signing Keys

The Tauri updater requires signing keys to verify the integrity of update packages.

```bash
# Generate key pair (will prompt for password)
npx @tauri-apps/cli signer generate -w ~/.tauri/mobaus.key

# Example output:
# Your public key was generated successfully:
# dW50cnVzdGVkIGNvbW1lbnQ6IG1pbmlzaWduIHB1YmxpYyBrZXk6...
#
# Your secret key was generated successfully - Keep it secret!
# ~/.tauri/mobaus.key
```

#### GitHub Secrets Configuration

Add the following Secrets in GitHub repository settings:

| Secret Name                              | Description                                          |
|------------------------------------------|------------------------------------------------------|
| `TAURI_SIGNING_PRIVATE_KEY`              | Private key content (~/.tauri/mobaus.key file content) |
| `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`     | Password set during key generation                   |

#### Configure Public Key

Fill in the generated public key in the `plugins.updater.pubkey` field of `tauri.conf.json`.

## 中文

### 模块职责

处理应用程序的自动更新检查和手动更新功能。

### 功能说明

1. **启动自动检查** - 应用启动时自动检查是否有新版本
2. **手动检查更新** - 用户可在设置页面手动触发检查
3. **下载并安装** - 检测到新版本后，下载并提示用户安装

### 技术方案

使用 Tauri 官方的 `tauri-plugin-updater` 插件，配合 GitHub Releases 作为更新源。

#### 更新流程

```
启动应用
    ↓
自动检查更新（静默）
    ↓
有新版本？ → 否 → 结束
    ↓ 是
显示更新提示对话框
    ↓
用户确认？ → 否 → 结束
    ↓ 是
下载更新包
    ↓
安装并重启
```

### 接口定义

#### 前端 API

##### checkForUpdates()

检查是否有新版本。

**返回：**

```typescript
interface UpdateInfo {
  available: boolean;      // 是否有新版本
  currentVersion: string;  // 当前版本
  latestVersion?: string;  // 最新版本
  releaseNotes?: string;   // 更新说明
  downloadUrl?: string;    // 下载地址
}
```

##### downloadAndInstall(onProgress?)

下载并安装更新，完成后自动重启应用。

**参数：**

- `onProgress` (可选): 下载进度回调函数 `(downloaded: number, total: number) => void`

**返回：**

- 成功: 调用 `relaunch()` 重启应用
- 失败: 抛出错误

**注意：**

Tauri v2 的 `@tauri-apps/plugin-updater` 中，`update.downloadAndInstall()` 完成后**不会自动重启**，必须手动调用 `@tauri-apps/plugin-process` 的 `relaunch()` 来重启应用并应用更新。

#### Tauri 命令

##### check_update

检查更新。

**返回：**

```json
{
  "available": true,
  "current_version": "0.2.0",
  "latest_version": "0.3.0",
  "release_notes": "## 更新内容\n- 新增功能...",
  "download_url": "https://github.com/..."
}
```

##### install_update

下载并安装更新。
