# 设置

在设置页面可以自定义应用的外观、语言，以及管理数据备份。

## 打开设置

点击侧边栏底部的「⚙️ 设置」图标。

---

## 通用设置

### 外观

支持三种显示模式：

| 模式 | 说明 |
|------|------|
| 浅色模式 | 白色背景，适合日间使用 |
| 深色模式 | 深色背景，适合夜间或低光环境 |
| 跟随系统 | 自动跟随操作系统的明暗设置 |

### 语言

支持以下界面语言：

- 简体中文
- English (US)

首次启动时会自动检测系统语言。切换语言后界面会立即生效。

---

## 数据管理

### 备份与恢复

你可以导出或导入所有配置数据，包括：

- 对话记录
- 圆桌会议记录
- Agent 配置
- 技能配置
- MCP 服务器配置
- 模型配置
- 应用设置

#### 导出配置

1. 点击「导出配置」
2. 勾选需要导出的项目
3. 点击「导出」，文件将保存到本地

#### 导入配置

1. 点击「导入配置」
2. 拖放或选择之前导出的配置文件（.json）
3. 选择是否「合并现有配置」（保留当前配置，仅添加新内容）
4. 可选择「导入前备份」（推荐）
5. 点击「开始导入」

> 💡 建议定期导出配置作为备份，以防数据丢失。

### 存储空间

显示当前本地存储的使用量，包含所有对话记录和缓存文件。

如需释放空间，可以点击「清除所有数据」。

> ⚠️ 清除数据将永久删除所有本地数据且无法恢复，请确保已备份重要数据。
