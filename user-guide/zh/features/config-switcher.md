# 配置同步 (Config Switcher)

MobausStudio 不仅可以作为一个独立的 AI 客户端，还可以将你的 AI 提供商和 MCP 配置同步到其他支持的第三方工具中（比如命令行工具），实现配置中心化管理。

## 什么是配置同步？

当你使用第三方命令行工具（如 Claude Code、Gemini CLI、OpenCode 等）时，通常需要手动去各个工具的配置文件里填写 API Key 或配置 MCP 服务。

通过 MobausStudio 的 **配置同步** 页面，你可以直接将已经连接并验证通过的 AI 提供商凭证，一键导出给这些第三方工具使用，省去重复配置的麻烦。

---

## 支持同步的工具

目前 MobausStudio 支持将配置导出给以下工具：

- **Claude Code**：Anthropic 官方的 CLI 工具
- **OpenCode**：强大的开源 AI 代码助手
- **OpenClaw**：CLI AI 代理
- **Gemini CLI**：Google 的 Gemini 命令行工具
- **Codex**：相关的 AI 工具

---

## 如何使用配置同步

### 1. 打开配置同步页面

点击侧边栏的「**⚙️ 配置同步**」图标（该图标视你当前主题和版本可能位于设置周围）或者从相关入口进入配置同步页面。

### 2. 选择要配置的工具

在左侧（或顶部）选择你想要同步配置的第三方工具（例如：`claude-code`）。

### 3. 选择提供商

界面会列出当前已连接的、且兼容该工具的所有 **AI 提供商**：
1. 点击你需要同步过去的提供商（如 Anthropic，或者兼容 OpenAI 协议的自定义提供商）
2. 点击「**同步到该工具**」或「**启用**」

### 4. 确认同步

系统会自动生成兼容该工具的配置文件（如 `.claude.json` 或者相应的环境变量配置），并写入到该工具指定的配置目录下。界面上会展示配置导出的路径和状态。

---

## 同步 MCP 配置

当该工具支持 MCP（模型上下文协议）时，MobausStudio 也会顺带将你在客户端中启用的 MCP 服务器列表写入到该工具的配置中。

也就是说，你只需要在 MobausStudio 中配置一次 MCP 服务器，所有支持的命令行工具都可以自动复用这些强大的能力。

---

## 常见问题

### 同步后，为什么工具没有生效？
某些命令行工具在运行期间会缓存配置，同步完成后，建议重启该工具或新开一个终端窗口。

### 导出了错误的配置怎么办？
只需要在配置同步页面，重新选择正确的提供商并再次同步，新的配置会覆盖旧的配置。
