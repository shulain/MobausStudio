# 圆桌会议

圆桌会议是 MobausStudio 的多 Agent 协作模式。你可以让多位不同角色的 Agent 围绕同一主题讨论，快速获得更全面的结论。

---

## 适合什么场景

- **方案评审**：让架构、研发、测试等角色一起看同一方案
- **产品讨论**：从业务、技术、体验等不同角度评估优先级
- **复杂问题拆解**：先多角度讨论，再整理为可执行行动项

---

## 3 分钟快速开始

1. 进入「对话」页面，点击「**编排对话**」
2. 选择「**圆桌会议**」模式
3. 填写讨论主题，添加参与者（建议 2-5 位）
4. 点击「**开始讨论**」

> 建议：参与者角色尽量不要重复，比如“产品经理 + 架构师 + 用户体验设计师”。

---

## 如何配置一次高质量讨论

### 1) 主题写清楚

比起“帮我看看这个功能”，更推荐：

- 我们要解决什么问题
- 希望达到什么目标
- 你最关心哪些维度（成本、速度、体验、风险等）

### 2) 补充背景信息（可选）

你可以填写团队现状、已有数据、已尝试方案，帮助 Agent 直接进入正题。

### 3) 添加约束条件（可选）

例如预算、时间、资源上限。这样讨论结果会更贴近可落地方案。

---

## 讨论进行中你可以做什么

- **继续追问**：针对某条观点深挖
- **@ 指定角色发言**：例如 `@架构师 请评估可扩展性`
- **随时调整方向**：补充新信息，避免讨论跑偏

### 工具调用展示

当参与者在讨论中调用工具时，你会看到独立的工具执行卡片（包含调用和结果），便于判断结论依据。

---

## 讨论结束后

点击「**生成总结**」后，你可以得到：

- 关键观点汇总
- 主要共识与分歧
- 可执行建议清单

如果还没讨论充分，也可以继续追加问题再总结。

---

## 使用建议

1. **先广后深**：第一轮先收集观点，再聚焦争议点
2. **角色明确**：角色名称越具体，输出越稳定
3. **信息逐步补充**：不要一次塞太多，按轮次补充最有效
4. **关注可执行性**：要求给出“下一步行动 + 负责人建议 + 优先级”

---

## 常见问题

### 参与者越多越好吗？

不一定。通常 2-5 位最合适，太多会让重点分散。

### 圆桌会议和普通对话怎么选？

- 需要快速回答、执行单任务：用普通对话
- 需要多视角评估、对比与决策：用圆桌会议

### 讨论记录会保存吗？

会。圆桌会议会作为对话记录保存，后续可继续追问。
