# 使用统计

统计页面展示你的 AI 使用数据概览，帮助了解使用情况。

## 打开统计

点击侧边栏底部的「📊 统计」图标。

---

## 统计指标

### 消息数

显示你发送和接收的消息总数，支持按时间范围查看：

| 时间范围 | 说明 |
|----------|------|
| 今日 | 当天的消息统计 |
| 本周 | 本周的消息统计 |
| 本月 | 本月的消息统计 |

### Token 使用

展示 AI 模型消耗的 Token 总量。

### 费用

基于模型定价估算的使用费用。

---

## 模型使用分布

以图表形式展示各模型的使用占比，帮助你了解哪些模型用得最多。

---

## 最近活动

展示最近的操作记录，包括：

- 创建新对话
- 启用技能
- 编辑 Agent
- 连接 MCP 服务器

---

## 导出报告

点击「导出报告」可以将统计数据导出，方便存档或分析。
