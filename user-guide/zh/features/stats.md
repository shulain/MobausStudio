# 使用统计

统计页面展示你的 AI 使用数据概览，帮助了解使用情况。

## 打开统计

点击侧边栏底部的「📊 统计」图标。

---

## 统计指标

### 消息数

显示你发送和接收的消息总数，支持按时间范围查看：

| 时间范围 | 说明 |
|----------|------|
| 今日 | 当天的消息统计 |
| 本周 | 本周的消息统计 |
| 本月 | 本月的消息统计 |

### Token 使用

展示 AI 模型消耗的 Token 总量，区分了输入 (Prompt) 和输出 (Completion) 的消耗，帮助你更精确地评估花费。

### 费用

基于模型提供商的市场公开定价估算的累计使用费用。

---

## 模型使用分布

以直观的饼状图等形式展示各模型（如 GPT-4o, Claude 3.5 Sonnet 等）的使用占比，帮助你了解最常使用的模型，方便你在续费或分配预算时做参考。

---

## 最近活动

展示最近的操作记录，包括：

- 创建新对话
- 启用技能
- 编辑 Agent
- 连接 MCP 服务器

---

## 导出报告

点击「导出报告」可以将统计数据导出为文件，方便存档或做进一步分析。

---

## 使用建议

- **定期查看统计**：养成查看统计的习惯，能帮你发现使用趋势和优化空间。
- **合理控制 Token 消耗**：如果 Token 消耗过高，可以考虑使用更轻量的模型处理简单任务（如 GPT-3.5 Turbo、Claude 3 Haiku）。
- **关注费用估算**：当使用按量计费的模型时，费用面板可以帮你避免意外的高额账单。
