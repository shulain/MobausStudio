# Usage Statistics

The Statistics page displays an overview of your AI usage data to help you understand your usage patterns.

## Open Statistics

Click the "📊 Statistics" icon at the bottom of the sidebar.

---

## Statistical Metrics

### Message Count

Displays the total number of messages you've sent and received, with support for viewing by time range:

| Time Range | Description |
|------------|-------------|
| Today | Message statistics for the current day |
| This Week | Message statistics for the current week |
| This Month | Message statistics for the current month |

### Token Usage

Shows the total amount of tokens consumed by AI models.

### Cost

Estimated usage cost based on model pricing.

---

## Model Usage Distribution

Displays the usage proportion of each model in chart form, helping you understand which models are used most frequently.

---

## Recent Activity

Shows recent operation records, including:

- Creating new conversations
- Enabling skills
- Editing agents
- Connecting MCP servers

---

## Export Report

Click "Export Report" to export statistical data for archiving or analysis.
